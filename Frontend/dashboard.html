Mamdani Fuzzy Logic Architecture

Fuzzification (Triangular/Trapezoidal MFs) → Rule Base Evaluation (MIN antecedent aggregation) → Aggregation (MAX composition) → Defuzzification (Centroid COG).

Fuzzy Membership Functions Illustration

Soft Computing Pipeline

1. Input Fuzzification: Converts scalar input values into linguistic terms (Low, Medium, High) using membership functions $\mu(x)$.

2. Rule Evaluation: Computes rule firing strength $w_i = \min(\mu_{A}(x_1), \mu_{B}(x_2))$ across 30 expert rules.

3. Output Aggregation: Combines clipped output fuzzy sets: $\mu_{out}(y) = \max_i(\min(w_i, \mu_{C_i}(y)))$.

4. Defuzzification: Calculates continuous Academic Risk Score $z^* = \frac{\int y \cdot \mu_{out}(y) dy}{\int \mu_{out}(y) dy}$.
